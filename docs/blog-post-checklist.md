# she persisted — episode post checklist

The website builds each episode page automatically from the Squarespace post, the podcast feed and YouTube. It only works if the post follows this structure. Everything below is what the recent posts already do; this just writes it down.

## 1. Squarespace post

**Title:** starts with the episode number, a period and a space, then the lowercase title.
`264. why your friends matter more than you think (feat. dr. jane smith)`

**Tags:** choose from the existing tags (anxiety, depression, relationships, dbt, college, 20s, self-improvement, emotions, trauma, body image, career, sleep, adhd, social media, teen mental health, troubled teen industry). Add `sadie recommends` only for episodes Sadie wants featured. Tags drive the topic pages, so every post should have at least one.

**Thumbnail:** set the post's featured image. It's used everywhere the episode appears on the site.

**Body, in this order:**

1. **listen to this episode:** the usual platform links block.
2. **Description:** two or three short paragraphs. The first sentence (through the first `?` or `?!`) is shown in red on the page, so make it a question that hooks.
3. **pull quote:** one line, the quote Sadie wants on the page. Either

   `pull quote: nothing changes if you don't change SOMETHING.`

   or "pull quote:" as a heading with the quote on the next line. Write it lowercase. Words written in CAPS become the emphasized phrase (two to five words); leave it all lowercase and the emphasis is chosen automatically. This line is removed from the notes shown on the page.
4. **i talk about:** / **we talk about:** followed by a bullet list of the topics, one per bullet. These become the chapter titles.
5. **mentioned:** followed by the links, as a list.
6. The YouTube video block (the full episode).
7. The usual "About She Persisted" and "Recent Episodes" blocks.

Keep the headings spelled as shown (the colon matters). The transcript does **not** need to be pasted into the post anymore; it comes from the podcast feed.

## 2. Podcast host (Flightcast)

Publish the audio as usual. Put `ep. 264` in the episode description if the number isn't in the title. If chapters are wanted, add timestamped lines to the show notes, one per line:
`03:00 what to do if you're feeling hopeless`

## 3. YouTube

- Full episode: `ep. 264` in the title or the description.
- Shorts from the episode: `ep. 264` in the description. Shorts without it won't show on the episode page.

## What happens next

The site updates itself overnight (around 11pm Pacific). The new episode appears in the "latest" row and gets its own page with the description, chapters, transcript, pull quote and Shorts. If something looks wrong the next day, tell Sadie which episode and what's off.
